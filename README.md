# WindNova Group

Premium corporate website for WindNova Group — a renewable wind energy company.

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Framer Motion
- React Router 7
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
